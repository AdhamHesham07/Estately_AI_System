# Using Local Models with Ollama

To avoid API rate limits and keep your data private, you can use local models like **Llama 3** via Ollama.

## 1. Setup Ollama
1.  **Download & Install**: You have already installed the Ollama app.
2.  **Pull the Model**: Open your terminal and run:
    ```bash
    ollama pull llama3
    ```
3.  **Run the Server**: Ensure the Ollama app is running in your taskbar.

## 2. Agent Configuration

### Using as a Fallback (Current Setup)
The agent is currently configured to try Gemini first. If Gemini hits a rate limit, it will automatically fallback to `ollama/llama3`.

### Using as the Primary Model
To use Llama 3 for everything and avoid the cloud entirely, modify `1.Agent/1_agent_config.py`:

```python
AGENT_CONFIG = {
    # Set this to ollama/llama3
    "model": "ollama/llama3",
    
    "fallback_models": ["gemini/gemini-3-flash-preview"],
    ...
}
```

## 3. Benefits
- **No Rate Limits**: You can run thousands of requests without being blocked.
- **Privacy**: Your queries never leave your machine.
- **Speed**: Local models can be faster depending on your hardware.
